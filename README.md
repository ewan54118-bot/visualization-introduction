# 可视化导论 · VIS Lab

《可视化导论》课程网站重构作业。以学习为中心，重新设计课程组织、知识讲解与可视化实验。网站仅包含静态前端代码，不含视频，无需数据库、账号、构建工具或 npm 依赖。

## 本地运行

在 VS Code 终端中运行：

```powershell
python -m http.server 8080
```

浏览器访问 `http://localhost:8080`。也可以使用 VS Code 的 Live Server 扩展。直接打开 `index.html` 能显示页面，但建议使用 HTTP 服务，保证浏览器本地保存与剪贴板等功能正常工作。

## 部署到自己的 GitHub Pages

1. 将本文件夹的源码上传到你自己的 GitHub 仓库，确保 `index.html` 位于发布目录根部。
2. 打开仓库 **Settings → Pages**。
3. 选择 **Deploy from a branch**，选择你的分支（通常为 `main`）和 `/(root)`，保存。
4. 等待 GitHub 完成部署，通过 Pages 页面给出的地址访问。

所有站内静态资源使用相对路径，页面通过 URL hash 路由（如 `#course/1/0/read`），支持 `username.github.io/repository/` 子路径。刷新课程页不需要额外的服务器路由配置。本项目未执行远程发布。

## 功能

- **学习概览**：课程地图、真实本地进度、按完成日期统计的每周学习足迹、继续学习入口。
- **课程章节**：五章 27 个小节，章节搜索、收藏和学习中筛选。
- **小节学习**：知识讲解、27 个逐节对应的嵌入式交互演示、D3 v7 代码片段、带答案解析的自测、自动保存的个人笔记。
- **27 个章节内演示**：覆盖数据质量、DIKW、测量尺度、分组聚合、Data Join、Card 流程、分类树、布局折叠、真实事件传播、HSL、色阶、Lab 色域、色轮、科研配色、错误配色、对比度、冗余编码、人口标准化、坐标轴、拖点插值、倾角、Marching Squares、时间聚合、区间选择、日历联动、螺旋与故事线。
- **理论与操作闭环**：每个演示包含观察任务、可载入的任务场景、实时指标、公式、动态解释和数据说明；可固定结果 A，再修改实时图 B 进行对照。一键将当前参数、数值和理论解释写入本节笔记。
- **理论与图形逐点关联**：27 节 × 3 个理论要点，共 81 个验证场景。点击理论要点，在本节图形中载入对应参数和观察提示，所有操作都在课程学习中完成。
- **详细的双语讲解**：27 节均提供概念机制、方法推导、公式、计算案例、适用边界与迁移练习，支持按学习路径定位。
- **全局中英切换**：右上角切换中文或 English；导航、正文、代码注释、自测、图表、控制器、动态解释及提示同步切换。语言偏好持久保存，不重建实验，不清除参数、快照或个人笔记。用户输入保持原文。
- **可复核的交互结果**：展开计算明细查看数据与参数，导出本节 CSV。固定快照后显示 A/B 指标对照和可计算的数值差异。
- **学习工具**：全局搜索（Ctrl/Cmd + K）、学习路线、知识速查、外部学习资源。
- **数据导出**：Markdown 笔记、学生 CSV、时序 CSV、实验 SVG。
- **访问体验**：响应式布局、深浅色模式、键盘操作、可聚焦图形提示、减少动态效果、打印阅读样式。

## 数据与内容说明

课程结构参考 [李昕老师的原课程网站](https://cinger007.github.io/vis/)，保留数据、数据可视化流程、色彩专题、低维数据可视化、时序数据可视化五章及 27 节主线。讲解提要、自测和实验为重新编写；原站完整理论与案例通过外部链接保留。主要参考教材为陈为等《可视化导论》。本站不是原课程全部内容的镜像。

所有实验数据均为固定规则生成的**教学合成数据**，图中注明来源；不用于真实人群或业务推断。灰度预览不等于色觉缺陷模拟。D3 代码页展示教学片段，需要在自行引入 D3 v7 的环境中补齐变量后运行；本站实验使用原生 SVG，不加载 D3 CDN。

## 学习记录与隐私

进度、收藏、笔记、自测、各小节的实验参数和主题保存在当前浏览器的 `localStorage`，键名为 `vis-lab-learning-v1`。没有数据上传和跨设备同步。实验默认静止，只有用户点击播放后推进；离开页面或切换浏览器标签会停止播放。清理浏览器数据或更换站点域名会导致原记录不可见；重要笔记请使用「我的笔记 → 导出笔记」备份。删除笔记后有短时撤销入口。关闭本地存储时，网站仍可学习，但会提示无法持久保存。

## 交互与算法参考

内置算法用于教学，不通过在线库执行。曲线演示使用带斜率限制的单调三次 Hermite；分类树采用叶节点等距、父节点居中的教学布局；等值线使用 Marching Squares 与边上线性插值；Lab 切片使用 D65 白点的 Lab → XYZ → sRGB 计算。页面明确区分教学实现与 D3 原始 API，避免声称所有坐标与 D3 实现逐点一致。

理论和 API 对照参考：[D3 曲线文档](https://d3js.org/d3-shape/curve)、[D3 树布局](https://d3js.org/d3-hierarchy/tree)、[D3 等值线](https://d3js.org/d3-contour/contour)、[D3 颜色空间](https://d3js.org/d3-color)。

可选的开发验证脚本：`tests/browser.cjs` 检查原有功能，`tests/learning-demos.cjs` 检查 27 个嵌入实验、拖动、区间选择、参数保存、笔记联动及关键数值计算。测试需要测试机上的 Node、Playwright 和 Chrome，不属于网站运行依赖。

`tests/bilingual.cjs` 检查双语内容、语言持久保存、切换可逆性、笔记与参数保留、表格导出和五种视口。`tests/collect-language.cjs` 遍历所有页面、27 节的四类学习内容、81 个理论场景及可用控制选项，检查英文界面未翻译文本与可访问标签；残留清单输出至 `test-results/i18n-missing.json`，发现残留或脚本异常时退出失败。用户笔记与中英按钮上的“中”不属于待翻译文案。

新增详细理论请在 `lesson-details.js` 同时提供 `zh` 和 `en`；新增界面短语加入本地字典。演示使用中文的内部数据标识与枚举值，英文只改变呈现，不改变算法输入。所有翻译随网站源码提供，不调用在线翻译服务。

## 技术选择

原生 HTML / CSS / JavaScript + SVG，零运行依赖，无外部字体、图片或视频请求。课程学习、笔记和实验不依赖原网站在线；外部资源链接需要网络。不是 PWA，首次访问线上网站仍需网络；把源代码下载到本机后可以离线运行本地服务。
